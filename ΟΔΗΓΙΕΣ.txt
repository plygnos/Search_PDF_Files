ΑΝΑΖΗΤΗΣΗ ΜΕΣΑ ΣΕ ΑΡΧΕΙΑ — WINDOWS

1. Εγκατάστησε Python 3.10 ή νεότερη από https://www.python.org/downloads/windows/
   Στην εγκατάσταση επέλεξε «Add python.exe to PATH».
2. Κάνε διπλό κλικ στο «Εκκίνηση.bat».
   Την πρώτη φορά απαιτείται Internet ώστε να εγκατασταθούν δύο βιβλιοθήκες.
   Τις επόμενες φορές ανοίγει απευθείας, χωρίς Internet.
3. Επίλεξε φάκελο και γράψε όρους αναζήτησης.
4. «Όλες οι λέξεις»: κάθε αρχείο πρέπει να περιέχει όλους τους όρους.
   «Οποιαδήποτε λέξη»: αρκεί ένας όρος.
   Για ολόκληρη φράση βάλε διπλά εισαγωγικά, π.χ. "Ωραιοζήλη Λεβή".
5. Διπλό κλικ στο αποτέλεσμα για άνοιγμα. Υπάρχει και κουμπί
   που δείχνει τη θέση του αρχείου στον Explorer.

Υποστηρίζονται: DOCX, DOCM, PDF (με επιλέξιμο κείμενο), TXT, RTF,
MD, CSV, LOG, JSON, XML, HTML, XLSX, XLSM, PPTX.

Η αναζήτηση δεν ξεχωρίζει κεφαλαία/πεζά ούτε τόνους: «Λεβή» = «λεβη».

ΠΕΡΙΟΡΙΣΜΟΙ
- Παλιά αρχεία .DOC και .XLS δεν υποστηρίζονται στην πρώτη έκδοση.
  Μπορείς να τα μετατρέψεις σε .DOCX / .XLSX.
- Σαρωμένα PDF που περιέχουν μόνο εικόνες χρειάζονται OCR.
- Δεν δημιουργείται ευρετήριο: σε κάθε νέα αναζήτηση τα αρχεία διαβάζονται ξανά.
- Δεν γίνεται αναζήτηση στο περιεχόμενο εικόνων.
- Το πρόγραμμα δεν ανεβάζει τα αρχεία σε υπηρεσία: η αναζήτηση γίνεται στον υπολογιστή.
- Σε φάκελο συγχρονισμένο με cloud, αρχεία που είναι μόνο online ίσως χρειαστούν κατέβασμα.

ΑΥΤΟΝΟΜΟ EXE
Αν θέλεις να δημιουργήσεις .exe που ανοίγει χωρίς εγκατάσταση Python,
τρέξε το «Δημιουργία_EXE.bat» σε υπολογιστή Windows με Python.
Το αποτέλεσμα θα είναι στο dist\Search_PDF_Files.exe.
Αν το Windows Defender εμφανίσει προειδοποίηση για άγνωστη εφαρμογή,
επίλεξε «Περισσότερες πληροφορίες» και έλεγξε ότι εκτελείς το δικό σου build.

BUILD ΜΕΣΩ GITHUB ACTIONS
Αν το project βρίσκεται σε δημόσιο GitHub repository, άνοιξε την καρτέλα
Actions και επίλεξε «Build Windows executable» → «Run workflow».
Μπορείς επίσης να ξεκινήσεις build κάνοντας push αλλαγές στο repository.
Όταν ολοκληρωθεί, άνοιξε το συγκεκριμένο run και κατέβασε το artifact
«Search_PDF_Files». Το artifact διατηρείται για 14 ημέρες.

ΔΗΜΟΣΙΑ ΛΗΨΗ ΧΩΡΙΣ ΣΥΝΔΕΣΗ
Για μόνιμη δημόσια λήψη, δημιουργείται GitHub Release όταν κάνεις push
version tag, π.χ. v1.0.0. Το Search_PDF_Files.exe επισυνάπτεται στο Release
και μπορεί να κατέβει χωρίς σύνδεση στο GitHub.
